# Workshop Documents

> Not affiliated with or endorsed by the FreeCAD project or the FPA; FreeCAD is the FPA's trademark. Get FreeCAD itself from [freecad.org](https://freecad.org).

Workshop Documents writes the papers that go with a part. It makes drawing
sheets with the standard views, sections, dimensions with ISO 286 fits, hole
callouts and a title block, as a TechDraw page and as SVG, PDF and DXF files.
It makes assembly manuals step by step, with exploded views, balloons and a
bill of materials. It draws patent-style figures and starts a draft for a
patent attorney to work from. And it packs your parts to share, as STEP and
STL with a README, a licence and credits, with nothing personal in the files.
It is for makers who need to hand a part to someone else, and for people who
let an AI agent write those papers with them.

<!-- screenshot: the Workshop Documents workbench with a drawing sheet open -->

You do not need to know Python or TechDraw. You do not need an agent.

## Install

You need FreeCAD 1.0 or newer.

**With the Addon Manager (custom repository).** This installs all four
Workshop add-ons (Parts, Make, Electronics, Documents) together.

1. Open **Edit ▸ Preferences ▸ Addon Manager**.
2. Under **Custom repositories**, add
   `https://github.com/jamesK1000011/Workshop-FreeCAD` with branch `main`.
3. Open **Tools ▸ Addon manager**, find **Workshop for FreeCAD**, and click
   **Install**.
4. Restart FreeCAD.

**As part of Agent Link.** The Agent Link extension for Claude Desktop
installs Workshop Documents for you, on its own, as `Mod/WorkshopDocuments`.
Nothing else to do.

**By hand.** Put this `Documents` folder in FreeCAD's `Mod` folder as
`WorkshopDocuments` and restart FreeCAD.

Use one way, not two: the same workbench installed twice shows up twice.

## What you see in FreeCAD

**The Workshop Documents workbench.** Pick it from the workbench list. Its
toolbars and its **Documents** menu have:

- **Drawings**: **Drawing** (a dimensioned sheet of standard views: a
  TechDraw page, and SVG, PDF and DXF files), **Exploded Drawing** (an
  assembly manual with exploded views, balloons and a bill of materials).
- **Share**: **Library Pack** (the parts as STEP and STL with a README, a
  licence and credits).
- **Patent**: **Patent Figures** (line figures with reference numerals),
  **Patent Draft** (a draft to start a patent attorney's work from).
- **Manual Panel**: the Manual tab.

<!-- screenshot: the Documents toolbars: Drawings, Share, Patent -->

**Task panels.** Drawing and Exploded drawing open a panel in the **Tasks**
tab, like FreeCAD's own tools. **OK** makes it as one undo step.

<!-- screenshot: the Drawing task panel -->

**The Manual tab**, beside the model tree (**Documents ▸ Manual Panel**).
Build an assembly manual a step at a time: tick the parts that go on next,
name the step, and click **Add step**. When the steps are done, click
**Make manual**.

<!-- screenshot: the Manual tab with three steps listed -->

Each button runs the same code an agent's tool does. Panels take their
colours from your FreeCAD theme. A patent draft is a start for an attorney's
review, never a filing.

## What an agent can do with it

When Agent Link for FreeCAD is installed, an agent gets these tools. The list
is generated from the tool definitions (`workshop_documents/data/tools.json`)
by `tools/gen_readme_tools.py`.

<!-- tools:begin (generated by tools/gen_readme_tools.py) -->
| Tool | Group | What it does |
|---|---|---|
| `drawing_make` | drawing | A drawing sheet of bodies. |
| `drawing_exploded` | drawing | An assembly manual. |
| `patent_figures` | drawing | Patent-style line figures of the parts, each with its reference numeral. |
| `patent_draft` | drawing | A Markdown draft of a patent description and a claims skeleton from the bodies. |
| `library_pack` | share | Pack bodies to share. |
<!-- tools:end -->

## Alone or with Agent Link

| | Alone | With Agent Link |
|---|---|---|
| Workbench, toolbars, task panels | Yes | Yes |
| Manual tab | Its own "Documents" dock | A tab in Agent Link's panel |
| Make manual | Documents' own exploded drawing | Another add-on's manual maker if one is installed, else the same |
| Agent tools above | No | Yes |

Workshop Documents needs no other add-on. It never imports Agent Link: only
`workshop_documents/agentlink_families.py` and the `fam_*` modules it loads
do, and only Agent Link loads them.

## Data

The filament table (`workshop_documents/data/filaments.json`), for the parts'
materials on drawings and in packs, is a data file with a schema, each entry with its source
and date, under CC BY 4.0 (`LICENSE-DATA`). Your own entries go in
`~/.config/workshop_documents/filaments.json`; updates never touch that
folder, and your entries win.
