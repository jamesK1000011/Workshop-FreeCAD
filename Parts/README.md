# Workshop Parts

> Not affiliated with or endorsed by the FreeCAD project or the FPA; FreeCAD is the FPA's trademark. Get FreeCAD itself from [freecad.org](https://freecad.org).

Workshop Parts makes standard parts to the size you ask for: Gridfinity bins
and baseplates, project boxes with lids, and enclosures round a circuit
board. You type a few numbers (how many cells, how tall, how thick the
walls) and the part appears in your document, each piece its own body, ready
to print. It is for anyone who wants a useful part without drawing it from
scratch, and for people who let an AI agent build parts for them.

<!-- screenshot: the Workshop Parts workbench with a Gridfinity bin in the 3D view -->

You do not need to know Python. You do not need an agent.

## Install

You need FreeCAD 1.0 or newer.

**With the Addon Manager (custom repository).** This installs all four
Workshop add-ons (Parts, Make, Electronics, Documents) together.

1. Open **Edit ▸ Preferences ▸ Addon Manager**.
2. Under **Custom repositories**, add
   `https://github.com/jamesK1000011/Workshop-FreeCAD` with branch `main`.
3. Open **Tools ▸ Addon manager**, find **Workshop for FreeCAD**, and click
   **Install**.
4. Restart FreeCAD.

**As part of Agent Link.** The Agent Link extension for Claude Desktop
installs Workshop Parts for you, on its own, as `Mod/WorkshopParts`. Nothing
else to do.

**By hand.** Put this `Parts` folder in FreeCAD's `Mod` folder as
`WorkshopParts` and restart FreeCAD.

Use one way, not two: the same workbench installed twice shows up twice.

## What you see in FreeCAD

**The Workshop Parts workbench.** Pick it from the workbench list. Its
**Parts** toolbar and menu have one button for each part:

- **Gridfinity Bin…**: a bin made to size: cells, height, lip, magnets,
  dividers.
- **Gridfinity Baseplate…**: pockets for bins, open or with magnet holes.
- **Project Box…**: a box with its lid, with optional screw bosses.
- **Board Box…**: an enclosure round a circuit board, with standoffs and a
  lid.

<!-- screenshot: the Parts toolbar with its four buttons -->

**A task panel for each part.** Each button opens a panel in the **Tasks**
tab, beside the model tree, like FreeCAD's own tools. Each value shows its
range. A line under the values says, as you type, if a value is out of range
or what fit your printer gets. **OK** makes the part as one undo step;
**Cancel** leaves the document as it was.

<!-- screenshot: the Gridfinity bin task panel with its values and the live line -->

Holes get your printer's fit calibration if you made one with Workshop
Make's **Calibrate Printer**; without one, they are made 0.2 mm big.

**From Python or a macro:**

```python
from workshop_parts import api
api.make(App.ActiveDocument, "gridfinity_bin", {"x": 2, "y": 1, "units": 4, "magnets": True})
```

## What an agent can do with it

When Agent Link for FreeCAD is installed, an agent gets these tools. The list
is generated from the tool definitions by `tools/gen_readme_tools.py`.

<!-- tools:begin (generated by tools/gen_readme_tools.py) -->
| Tool | Group | What it does |
|---|---|---|
| `gen_make` | parts | Make a Gridfinity bin to size. |
| `gen_part` | parts | Make a standard part to size, each piece its own body. |
<!-- tools:end -->

While the agent works, you see the Workshop Parts workbench and the button
for the part it is making light up.

## Alone or with Agent Link

| | Alone | With Agent Link |
|---|---|---|
| Workbench, toolbar, task panels | Yes | Yes |
| Python API (`workshop_parts.api`) | Yes | Yes |
| Agent tools above | No | Yes, listed by default |

Workshop Parts needs no other add-on. It never imports Agent Link: only
`workshop_parts/agentlink_families.py` and `fam_parts.py` do, and only Agent
Link loads them.

## Data

The hardware table (`workshop_parts/data/metric-hardware.json`) is a data
file with a schema, each entry with its source and date, under CC BY 4.0
(`LICENSE-DATA`). Your own entries go in
`~/.config/workshop_parts/metric-hardware.json`; updates never touch that
folder, and your entries win.
