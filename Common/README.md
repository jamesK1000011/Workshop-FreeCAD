# Workshop Common

> Not affiliated with or endorsed by the FreeCAD project or the FPA; FreeCAD is the FPA's trademark. Get FreeCAD itself from [freecad.org](https://freecad.org).

Workshop Common is no longer needed. It used to hold the shared **Workshop**
workbench; now Workshop Parts, Make, Electronics and Documents each have
their own workbench and work alone. This last release (0.4.0) registers
nothing. It prints one line at start saying so.

## What to do

If you have it, remove it: delete `WorkshopCommon` from FreeCAD's `Mod`
folder, or uninstall it in the Addon Manager. Nothing else uses it. The
Addon Manager install of Workshop for FreeCAD does not include it.
